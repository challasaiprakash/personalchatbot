PROJECT 6: Real-Time Forecasting of Extractable Energy in PCM Thermal Storage
- Category: Applied Machine Learning (Internal project at VSB-TUO for another research team)
- Timeline: [add dates]
- Core Tech Stack: Python, scikit-learn (Gradient Boosting Regressor), Pandas, NumPy, Joblib, PyQt5
- Key Deliverables & Achievements:
  * Built a live Gradient Boosting system that forecasts a phase-change-material (PCM) heat-storage tank from the operator's target temperature and holding time plus live sensor data: end of heating, end of holding, end of cooling, total extractable energy (kWh), and the full energy-versus-time curve.
  * The first forecast is issued 3 minutes after heating starts and updates every 10 seconds as new sensor data arrives.
  * Engineered 20 live features (temperature slopes, charging rate, warm-up power) and prevented data leakage with grouped cross-validation, a fully held-out test set, and a truncation test proving each forecast uses only data observed so far.
  * Results from the first 3-minute forecast on held-out runs: end of heating predicted within 1.6 min (R2 0.995), end of holding within 5.4 min (R2 0.989), total extractable energy within 0.27 kWh (R2 0.984); energy curve MAE 0.26 kWh (R2 0.975).
  * Delivered a PyQt5 live GUI that updates in about 23 ms per sensor row, freezes past forecasts so they are never revised, and enforces energy conservation (extractable energy never exceeds input energy) in training; covered by a 73-check automated test suite.
